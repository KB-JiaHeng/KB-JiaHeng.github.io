YOLO Hero — Artwork Sources

These four WebP images are the runtime image layers used by the homepage’s DOS-style torn-screen animation. The original high-resolution downloads are not required for playback or for hexo generate.

How these images are used

  • Stoic variant: stoic-fresco.webp is the moving fresco background; stoic-scholars.webp is a separately cropped, transparent-edged detail with the original figure’s painted anatomy preserved. The text ARETÊ is a website overlay, not an inscription from Raphael’s fresco. The depicted youth should not be presented as Marcus Aurelius.
  • Buddhist variant: buddha-thangka.webp is the moving painting background; buddha-gilded.webp is a cut-out photograph of a gilded sculpture. They come from different artworks and traditions, intentionally juxtaposed. Om! is a website overlay.
  • Masks, animation and color treatments: Applied at runtime using themes/hexploit/source/css/yolo-corruption.css, themes/hexploit/source/css/yolo-gallery.css, and themes/hexploit/source/js/yolo-corruption.js. Neither the tear shape nor the text is baked into the WebPs.

The WebPs are derived assets (cropped/resized/recolored; the scholars layer has a torn-paper alpha edge, and the statue layer has a removed photo background). Retain this README when copying the images or publishing the website to preserve source attribution.

For future recropping, redownload the higher-resolution originals from the linked institutions. No image in this folder depends on retaining a separate artwork-sources/ directory.
