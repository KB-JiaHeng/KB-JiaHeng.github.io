完整的 2011 年 HTML 源码

我吓了一跳，虽然最近确实在学习俄语，但是没有任何印象自己在个人网站上标记过任何的俄语，所以大抵和我没有什么关系。再看 HTTP 标题<title>Мастер-Ф ремонт и строительные работы</title>，着实被俄国人的取名惊吓了一下 —— Master F。颇为文艺呵。再往后面看，才知道原来是个俄罗斯的装修公司网站。可网站对应的主机名叫做 example.com，而且放在 GitHub 的服务器上？ 有意思。于是我花了一些时间把网站复原了出来。

首先是根据 html 里的 src 和 href 等等，顺藤摸瓜，我恢复出了整个网站的模样。

看到这些照片，突然感觉有些触动。关于2011年，我已经不记得发生过什么事情了。但是家里的老式数码相机里依然存着家人和我在2011年时候的样子，存着那一年的种种景色和图景。我觉得完全和网站里这些照片的光彩是类似的。我未去过俄罗斯，但是这样的稍微有些暗淡的室内光打在墙壁上，外面寒冷至极，屋内暖而安心的感觉，是让我感到熟悉的。的确让人有一种家的感觉。或者说这样的温馨安全的感觉让我觉得有一种怀旧感。思绪渐渐又远去了……

我在瑞典和挪威呆过一小段时间，虽然去的时候是夏天，看不到任何的冰川或是积雪，但是看到当地人居住的房屋，尤其是林雪平市的房屋让我印象极深，我常常会想象从屋里往外看是什么样子的感觉。我想大概和这几张照片差不多舒适吧！

这几张照片给我带来的舒适感来自这样的场景想象：外面积雪皑皑，飞雪停了有一段时间了，天气依然阴沉沉的。家里的暖气叫人感觉完全与户外远远隔开了，但是你好像离外面又不是很远，因为窗外就是雪景，打开窗户还是会倒灌进来一阵寒风。家门口几棵叫不上名字的高树，凌凌地站在那里，黑漆漆的。这时候在想些什么呢？或许是 codeforces，或许是和哥们打游戏，或许是学校里的某个姑娘……无忧无虑，小镇就这么大，装不下任何的焦虑和忧愁。就青年时期的生活来说，在生活意义上与大都市隔绝也没有什么不好的。每天上学的时候有朋友、心仪的女孩值得期待，放学之后还有爸妈做的饭菜值得期待。晚上睡觉的时候，梦都是甜的。

但是这个网站怎么能叫 example.com 呢？根据 IANA 记载，自 1992年01月01日 开始example.com 就已经存在；而至少从 1999年6月 开始， example.com就已经是保留域名了。这个网站从一开始就无法通过 example.com 访问到，到底是哪个笨蛋前辈程序员在 GitHub 上忘记修改了 CNAME 呢（楽）。

公司其司 & 负责人其人

网页标题下面写着：

Мастер-Ф (Master - F)
Строительные и отделочные работы (建筑与装修工程)
г. Тверь (特维尔市，г. 是俄语 город 的缩写)

我们从这里得到了公司的服务范围、地址和名称。

然后网页上面有个 Клиенты о нас (顾客如何评价我们)，第一个评价就是

Благодарим коллектив ООО «Мастер-Ф» в лице дирректора Филиппова Игоря Анатольевича за высокую организацию и проведение ремонтно-строительных и отделочных работ, долгосрочное сотрудничество с нашим предприятием. (АО «АЛВИСТ» Генеральный директор В.А. Александров)

我们感谢 ООО «Мастер-Ф»（Master-F有限责任公司） 全体员工，特别是公司负责人 Филиппова Игоря Анатольевича，感谢贵方对维修、建筑及装修工程所进行的高水平组织与实施，以及长期以来与本企业的合作。(“ALVIST”股份公司 维克托尔·阿列克谢耶维奇·亚历山德罗夫)

注: дирректора应为директора，可能是当时网站制作者的笔误。Александров 其人的信息在特维尔市 2004 年城市日庆典上市长感谢信里有所印证。

директор 是 director 的意思，俄语公司语境里的通常就是公司的法定/行政负责人的意思。据此可以猜测这是一家规模不大的公司，公司的老板可能就是 Филиппов Игорь Анатольевич 先生，转写为英文就是 Igor Anatolyevich Filippov.

我们去俄罗斯联邦税务局探索一番

第一个搜索结果就匹配了 Тверская область (特维尔州)，公司名字也叫Мастер-Ф，不过负责人的名字叫 Филиппов Андрей Анатольевич，英文转写为 Andrey Anatolyevich Filippov. 好家伙，开办的地点和公司名称一样，两人的姓和父称都一样，只是名字不同，傻瓜才会相信两人没有关系。

在第 28 项我们看到 Филиппов Игорь Анатольевич，这正是我们要找的人！也就是我们在俄罗斯的税务局里找到了这位先生的登记信息，而且有心者还可以发现 Игорь 和 Андрей 各自出资了 5000 卢布创建这家公司。我想知道，他们现在过得怎么样呢？

根据这份 PDF 开头的 ОГРН 1026900550951 和 ИНН 6902033541，我们完全可以确定下来这家公司了。GPT 给我分享了一个网站，告诉我里面显示 Master-F 这家公司平均在册员工数为 1。我没能打开这个网站，但也太幽默了，让我想起斯拉夫超人。

Tochka 的企业核查页面同样显示，截至 2026-04-16 公司仍在运营，并被列入俄罗斯中小企业名录中的 Микробизнес（微型企业）；它还给出了 2024 年财务数据：营业收入约 99.3 万卢布、支出 7.1 万卢布、净利润约 92.2 万卢布。

好吧，总共2个人做股东、1个人工作的公司，2024年还有93%的利润率，至少从2011年开始的企业活到了现在。Bravo… Очень хорошо!

结语

人生多有奇缘妙机啊。2001年 Филиппов 兄弟（如果没有猜错的话）在特维尔市联合创办了 Master-F，在 2011 年请了 Leonid 帮忙写网站。Leonid 写完网站之后留下了一个 CNAME test。岁月流转，到了 2026 年， Филиппов 兄弟的公司依然屹立，Leonid 成为了 Go 圈子里小有名气的人，而我写计算机网络作业，借助大语言模型，成为了看到这一切的人。

2001年、2011年，那依然是互联网的黄金年代。2026 年，大语言模型技术突飞猛进。千禧年初的俄罗斯，第一个一百年奋斗目标达成后的中国。事实就是没人能够知道未来是什么样子。不过，噢，我已经20岁了啊……
